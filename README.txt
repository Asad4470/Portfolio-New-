ASAD MULLA — DATA & AI PORTFOLIO SOURCE

FILES
- index.html: page structure and project content.
- style.css: all visual styles, layout, theme colors, and responsive rules.
- script.js: profile/project image loading and project-category filters.
- images/: place your profile photo and project screenshots here.

PREVIEW LOCALLY
1. Extract this ZIP to a folder.
2. Open index.html in a modern browser.
3. Keep style.css and script.js beside index.html.

CUSTOMIZE
1. Update your contact email in index.html (search for your.email@example.com).
2. Replace placeholder project links with the exact repository URLs.
3. Add images/profile.jpg and set profilePhoto in script.js.
4. Add project screenshots in images/ and fill projectImages in the same order as project cards.
5. Update descriptions and remove any project you cannot verify or explain.
6. For GitHub Pages, upload index.html, style.css, script.js, and images/ to the repository root.

NOTES
- This is the editable source package, not a published live website.
- Project links are placeholders until you replace them with specific repository links.
